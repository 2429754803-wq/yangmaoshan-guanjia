📖 使用说明

1. 首次使用：点击右上角"配置云服务"，填入 Supabase 项目 URL 和 service_role key（在 supabase.com 项目 Settings → API 中获取）
2. 生成授权码：填写商家名 → 点"生成授权码" → 复制发给商家
3. 商家激活：手机端注册登录后输入授权码即可使用；授权码不限制设备数和使用时间
4. 吊销：点商家行"吊销"，该授权码立即失效，商家手机端下次启动会提示授权被吊销
5. 发布更新：上传新版单文件到可访问地址 → 填版本号和地址 → 发布；商家手机端启动/点"检查更新"会收到提示
6. 先执行 supabase-setup.sql：在 Supabase SQL Editor 运行建表脚本（项目附带）
