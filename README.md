# 🧥 羊毛衫管家

洪合羊毛衫商家专用：**库存 · 销售 · 订单 · 盘点 · 进货 · 欠款 · 客户管理** 一站管理。
手机端 PWA（可添加到主屏幕），**支持电脑端授权管理与软件更新**。

## 二、散单改善功能（2.2 新增）

针对"网店散单多"场景（很多网店商家来进货、每单量小、笔数多）：

| 功能 | 说明 |
|---|---|
| **客户管理** | 独立"客户"Tab：客户档案（名称/电话/地址/备注）、搜索、每个客户的历史订单、累计进货额、欠款 |
| **快速开单** ⚡ | 从客户详情一键开单，自动带出电话地址；选客户→加商品→保存，几秒一单；支持"保存并继续开单"连续录入 |
| **批量导入** 📥 | 从网店后台导出订单整理成文本粘贴，一键生成多单（自动匹配款式扣库存、自动创建客户） |
| **批量操作** | 订单列表勾选多单 → 一键批量标记完成 |

**批量导入格式**（每行一单，逗号分隔）：
```
客户名,电话,地址,商品名,颜色,数量,单价
淘宝老张,13800000001,浙江杭州xx路,圆领羊毛衫,红色,5,60
```
- 商品名需与库存款式名一致才能自动匹配扣库存
- 未匹配的款式也会导入订单（不扣库存），并在预览时提示

## 二、三种使用模式

### 🏠 模式一：自己单机用（最简单，零配置）
- 直接用 `knit-stock-single.html`，注册账号即用
- 无需任何云端配置，数据存手机本地

### 🏪 模式二：店内多手机用（需配置云同步）
- 设置 → 云同步 → 填 Supabase 配置 → 多手机数据互通

### 🏭 模式三：分发软件给其他商家（完整授权体系）
- 电脑端用 `admin.html` 管理授权码和版本
- 商家手机端需要**输入授权码**才能激活使用
- 可以随时**吊销**某个商家的授权
- 有新版本时**一键发布**，商家手机自动提示更新

## 三、部署电脑管理后台（一次性配置）

### 第 1 步：创建 Supabase 项目（免费）
1. 注册 [supabase.com](https://supabase.com) → 创建项目（选 Free 计划）
2. 项目创建后，左侧菜单 **SQL Editor** → New query
3. 把项目附带的 **`supabase-setup.sql`** 全部内容粘贴进去 → **Run**
4. 建好 4 张表：`licenses`、`license_activations`、`app_versions`、`knit_sync`

### 第 2 步：配置电脑管理后台
1. 电脑浏览器打开 **`admin.html`**（或部署到任何地方）
2. 点右上角 **"配置云服务"**
3. 填入（在 Supabase 项目 **Settings → API** 里找）：
   - **Supabase URL**：如 `https://xxxx.supabase.co`
   - **Service Role Key**（服务端密钥，仅电脑后台用，别发给商家）
4. 保存 → 状态栏显示"已连接" ✅

### 第 3 步：开始运营
- **发授权码**：填商家名 → 生成 → 复制发给商家
- **吊销**：表格里点"吊销"，该商家手机立即失效
- **发版本**：上传新版单文件到可访问地址 → 填版本号+地址+说明 → 发布

## 四、手机端授权激活流程

1. 商家收到 `knit-stock-single.html`（或访问部署网址）
2. 手机浏览器打开 → 注册账号登录
3. 若已配置云端授权：提示**输入授权码** → 输入管理方发的码 → 激活 ✅
4. 之后每次打开：自动检查授权是否有效 + 是否有新版本
   - 授权被吊销 → 提示"请联系管理方"
   - 有新版本 → 弹窗提示更新（点开新版本页面）

> 未配置云端的手机：直接进入，不要求授权码（本地模式）。

## 五、手机安装（苹果/安卓）

### 🤖 安卓：打包 APK（安装包）
1. 先把应用部署到公网（Netlify/GitHub Pages），拿到 https 网址
2. 打开 [pwabuilder.com](https://www.pwabuilder.com) → 输入网址 → Android → 下载 APK
3. APK 发到手机点击安装

### 🍎 苹果：Safari"添加到主屏幕"
Safari 打开网址 → 分享按钮 → "添加到主屏幕" → 全屏使用

### 📄 单文件版
直接把 `knit-stock-single.html` 发到手机 → 浏览器打开即用（本地模式）。

设置 → 云同步 → 填 Supabase URL + anon key：
- **上传到云端** / **从云端拉取**：手动同步

## 七、数据与安全

- 手机数据默认存本机浏览器（IndexedDB）
- 账号密码 SHA-256 加盐哈希，不联网
- 授权码验证走 Supabase（HTTPS）
- **service_role key 权限极大，只填在电脑管理后台，绝不发给商家**

## 九、常见问题

**Q：商家手机收不到更新提示？**
A：检查管理后台是否发布过版本，且版本号与当前不同（当前内置版本 2.1）；手机端需联网且配置了云端。

**Q：吊销授权码后商家还能用吗？**
A：商家手机下次启动（或重新激活检查）时会被拦截，提示联系管理方。

**Q：忘记 service_role key 填哪里？**
A：只在电脑管理后台的"配置云服务"里填一次，浏览器本地保存，不会上传。

**Q：一个授权码能几台手机用？**
A：不限制设备数，一个授权码多台手机可共用；吊销即全部失效。
